Overview

SecSight is an AI-driven security operations platform built for small-and-mid SOC teams that don't have the headcount to staff a 24/7 detection and response function. It pairs a multi-agent SecOps Copilot with an auto-remediation SOAR engine so that routine incidents — phishing triage, false-positive sweep, IOC enrichment — are handled automatically under well-defined autonomy levels, while the complex ones land in a human review queue.

The system is shipped with a process-isolated deployment model and aligned with MLPS 2.0 (等保 2.0) so it can be installed in regulated environments without architectural rewrites.
